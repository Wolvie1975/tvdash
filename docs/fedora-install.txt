tvdash — Fedora Destination Machine Install Guide (RPM or Build + Players & Codecs)
===================================================================================

Run these steps in a terminal on the destination Fedora (GNOME Wayland) machine.

Option A: Install from the prebuilt .rpm (recommended — no Rust/source needed)
------------------------------------------------------------------------------
1. Copy dist/tvdash-0.1.0-1.x86_64.rpm from your build machine, then install it:
   sudo dnf install ./tvdash-0.1.0-1.x86_64.rpm
   (This installs /usr/bin/tvdash, the app-menu entry, mpv, and mpv-libs.)

2. Install full codecs + Brave (see step 3 below).


Option B: Build from source on the destination machine
------------------------------------------------------
1. Build dependencies
---------------------
sudo dnf install -y git gcc fontconfig-devel

2. Rust toolchain (skip if cargo is already installed)
------------------------------------------------------
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"

3. Players & codecs (mpv + full FFmpeg + Brave)
-----------------------------------------------
# mpv + libmpv (required for in-window video in TV-only mode)
sudo dnf install -y mpv

# Switch Fedora's ffmpeg-free to RPM Fusion's full ffmpeg (H.264 / HEVC picture)
sudo dnf install -y https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
sudo dnf swap -y ffmpeg-free ffmpeg --allowerasing
mpv --vd=help | grep -wE "h264|hevc"

# Optional: Intel hardware decoding (recommended for 4K on Intel graphics)
# sudo dnf install -y intel-media-driver
# mkdir -p ~/.config/mpv && echo "hwdec=auto" >> ~/.config/mpv/mpv.conf

# Brave browser (RPM repo, not Flatpak — needed for Widevine DRM)
sudo dnf install -y dnf-plugins-core
sudo dnf config-manager addrepo --from-repofile=https://brave-browser-rpm-release.s3.brave.com/brave-browser.repo
sudo dnf install -y brave-browser

4. Clone, build, and install tvdash
-----------------------------------
git clone https://github.com/Wolvie1975/tvdash.git ~/tvdash
cd ~/tvdash
git checkout laptop-redesign
cargo build --release -j 2
packaging/install.sh --autostart   # omit --autostart if you don't want login autostart
