# Watch on TV logos

Wordmarks for the ten fixed apps, bundled into the binary (`crates/app/src/logos.rs`).
Each `<id>.svg` is the original, used on the light themes (Stone, Mist); `<id>-dark.svg`
is used on Dark (and the TV layout's dark theme).

Originals downloaded from Wikimedia Commons on 2026-11-12:

| tubi.svg | File:Tubi logo.svg |

Dark variants: the same file with black or navy text recoloured to `#E8EAED`
(Apple TV, Disney+ including its arc, Tubi, YouTube TV, YouTube). The others are
unchanged copies.

These are the services' trademarks, used here only to label the tiles in a personal
app. If tvdash were distributed, each service's brand guidelines would apply.
